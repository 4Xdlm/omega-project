## 6. Pourquoi hors-source

Critères d'éligibilité à l'archivage hors-source :

1. **Résultat bench reproductible** : régénérable via `npm test -- --run <bench-script>` sur commit référencé
2. **Volume prohibitif** : cumul >5 MB (>30 JSON détaillés + rapports)
3. **Pas de dépendance in-source** : aucun test ni script ne lit ces fichiers depuis le repo
4. **Pattern transient** : résultat daté d'une campagne ponctuelle, non-canonique

Les modules de référence (corpus CSV, coefficients scellés M0b_slim V3.4, holdout V2) restent **in-source** car canoniques.
