### 4.1 Pourquoi la Romance marche — chaîne causale complète

```
Anxiété diffuse (niveau moyen-élevé constant dans société moderne)
  ↓
Besoin de résolution émotionnelle GARANTIE (certitude rare dans la vie réelle)
  ↓
La Romance = seul genre qui GARANTIT la résolution avant même l'achat (code HEA/HFN)
  ↓
Réduction du risque émotionnel d'investissement lecteur → conversion achat HAUTE
  ↓
Format ebook favorise confidentialité (pas de honte) → conversion HAUTE
  ↓
Lectorat à fort volume (5+ livres/mois) → recommandation HAUTE → bouche-à-oreille FORT
  ↓
Résultat : fond permanent 15-22%, inébranlable depuis 35 ans

MÉCANISME PHYSIQUE : Garantie de réduction d'anxiété + absence de friction d'achat
```

### 4.2 Pourquoi le Thriller marche — chaîne causale complète

```
Incertitude chronique (monde 2026 = information fragmentée, experts contestés, vérité floue)
  ↓
Besoin cognitif de résolution d'incertitude (anxiété spécifique de "ne pas comprendre")
  ↓
Le Thriller = promesse structurelle que l'incertitude SERA résolue (différent de la romance)
            = entraînement cognitif sur un danger fictif sécurisé
  ↓
Activation système sympathique (adrénaline) dans espace sécurisé → plaisir neurologique
  ↓
"Page-turner" = dopamine à chaque révélation → boucle de récompense → lecture compulsive
  ↓
Finish rate ÉLEVÉ → recommandation ("tu DOIS le lire") → bouche-à-oreille fort
  ↓
Résultat : fond permanent 18-24%, format audio #1 (écoute active en déplacement)

MÉCANISME PHYSIQUE : Résolution d'incertitude dans espace sécurisé + boucle dopaminergique
```

### 4.3 Pourquoi le Heroic Fantasy PURE décline — chaîne causale

```
Fantasy héroïque = monde secondaire avec règles claires, bien vs mal définis
  ↓

  le rend accessible (LOTR films, WoW, GoT)
  ↓
2025 : le monde réel n'est plus ambigu, il est CHAOTIQUE
      (chaos ≠ ambiguïté — le chaos ne se résout pas par un héros clair)

Aucun nouveau catalyseur médiatique Fantasy = pas de nouveau LOTR en vue
  ↓
Résultat : Heroic Fantasy pur → niche stable (~4-5%) sans catalyseur

MÉCANISME PHYSIQUE : Dépendance totale aux catalyseurs médiatiques externes
                     + inadéquation forme/anxiété contemporaine
```

### 6.2 Équation 2 V2 — Modèle hybride cycles + viraux

**Modèle macro (cycles normaux — sinusoïdale amortie, validé R²≈0.82) :**
```
V_macro(t) = V_base + A_macro × sin(2π(t-t₀)/T) × e^{-λ(t-t₀)}
```

**Modèle micro (chocs viraux — log-normale, apport Gemini) :**
```
V_viral(t) = V_base + A_viral × [1/(t·σ·√(2π))] × e^{−(ln(t)−μ)²/(2σ²)}

Paramètres calibrés sur BookTok/Yarros :
  μ = ln(0.5 ans) → peak à ~6 mois post-viral
  σ = 0.8 → longue traîne asymétrique
  A_viral = amplitude maximale du choc (ex: Yarros : +1M semaine 1)
```

**Modèle complet (hybride) :**
```
V(t) = V_macro(t) + V_viral(t) × CAC(t)

Où CAC(t) = Coefficient d'Amplification Culturelle au temps t
  = [Poids_Médiatique × Durée_Exposition] × Congruence(genre, IPC_t)
```

### 6.3 Équation 3 V2 — Succès Total unifié (synthèse 4 IA)

```
SUCCÈS_TOTAL(roman, t) = Q_interne(roman) × R_externe(roman, t) × P_sociale(roman, t) × A_usage(roman)

Q_interne = ISC_lin (opérationnel) ou ISC_ML (cible)

R_externe = f(IPC(t), Attractivité_genre(t), Timing_cycle(t))
          = Congruence(thème_roman, anxiété_collective_t) × (1 - Saturation_sous-genre(t))

P_sociale = (Bouche-à-oreille × 0.30) + (BookTok_fitness × 0.25) + (Adaptabilité_écran × 0.25)
           + (Prix_littéraires × 0.20)

A_usage = Intensité_émotionnelle / Effort_cognitif
        = (T + I + A) / (3 × FL × Complexité_perçue)

SUCCÈS_TOTAL ∈ [0, 1]
Seuil bestseller régional   : > 0.55
Seuil bestseller national   : > 0.68
Seuil bestseller mondial    : > 0.80
```

### 6.4 Résolution formelle paradoxe Maslej (apport Gemini — adopté)

```
RÈGLE D'IMPLÉMENTATION OMEGA :

COMPLEXITY_SYNTAXIQUE (à MAXIMISER) :
  ✓ Subordonnées, relatives, imbrications
  ✓ Alternance phrases très courtes / très longues (rythme)
  ✓ Chiasmes, anaphores, structures parallèles
  ✓ Retards syntaxiques (sujet éloigné du verbe)
  ✓ Propositions intercalées

FRICTION_LEXICALE (à MINIMISER) :
  ✗ Mots < top 10 000 fréquence (sauf si définissant voix d'un personnage spécifique)
  ✗ Jargon technique sans ancrage émotionnel
  ✗ Archaïsmes décoratifs
  ✓ Mots abstraits (douleur, absence, éternité) = autorisés — fréquents + évocateurs
  ✓ Mots concrets courants (table, main, pluie) = autorisés
  ✓ Mots valence négative courants = favorisés (Maslej 2021)

FORMULE OMEGA :
  Bonne prose = syntaxe sophistiquée + lexique accessible + valence négative dominante
  Mauvaise prose hermétique = syntaxe complexe + lexique rare + valence abstraite obscure
  Mauvaise prose commerciale = syntaxe simple + lexique courant + valence positive plate
```

### 7.6 La grande dissonance expliquée — Pourquoi Jury ≠ Lecteur

```
JURY DE PRIX LITTÉRAIRE recherche :
  1. Innovation formelle (rupture avec conventions)
  2. Ambition thématique (complexité du propos)
  3. Style remarquable (travail de langue visible)
  4. Originalité narrative (structure non conventionnelle)
  5. Contribution à la littérature (valeur historique)

→ Ces critères MAXIMISENT l'Effort cognitif (E dans I/E)
→ Ils ne maximisent PAS forcément l'Intensité émotionnelle (I dans I/E)

LECTEUR recherche :
  1. Identification personnage (Loi 3)
  2. Arc émotionnel satisfaisant (Loi 4)
  3. Transportation (Mécanisme principal)
  4. Surprise (Kunze 2023)
  5. Rapport I/E ≥ 2.0

→ Ces critères MINIMISENT l'Effort cognitif
→ Ils maximisent l'Intensité émotionnelle

ZONE OMEGA = trouver une prose qui satisfait les deux systèmes de valeurs
           = Innovation formelle MESURÉE + Accessibilité émotionnelle GARANTIE
           = C'est le segment upmarket fiction

FORMULE :
  Prix = f(Innovation, Ambition, Style pur)
  Ventes = f(I/E, Timing, Propagation)
  Amour = f(Identification, Resolution, Durabilité mémorielle)

  Jackpot = max(Prix × Ventes × Amour) simultanément
          → Nécessite I/E ≥ 1.8 ET style innovant ET thème résonant
          → Représente ~5-8% des bestsellers sur 35 ans
```
