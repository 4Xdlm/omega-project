lecteur, cycles culturels exogènes et prix littéraires.

de la qualité prose, pour adapter OMEGA à produire un roman à la fois chef

par convergence 4 IA.

## 6. ÉQUATIONS FINALES — VERSION PROGRAMME DE VÉRITÉ

### 6.1 Équation maîtresse unifiée (synthèse 4 IA)

```
SUCCÈS_TOTAL = Q_interne × R_externe × P_sociale × A_usage

Q_interne  = ISC = f(Transportation, Identification, Arc, Prose)
R_externe  = f(IPC(t), Attractivité_genre(t), Congruence)
P_sociale  = 0.30×BdO + 0.25×BookTok + 0.25×Écran + 0.20×Prix
A_usage    = Intensité_émotionnelle / Effort_cognitif
```

### 6.2 Loi ChatGPT formalisée

```
A_usage = I / E

Exemples calibrés :
  Colleen Hoover : I=0.90 / E=0.20 → 4.50 (best-seller massif)
  Dan Brown      : I=0.75 / E=0.15 → 5.00 (best-seller maximal)
  Hosseini       : I=0.92 / E=0.30 → 3.07 (best-seller + reconnu)
  Flaubert       : I=0.85 / E=0.75 → 1.13 (chef d'œuvre de niche)
  Proust         : I=0.95 / E=0.90 → 1.06 (chef d'œuvre absolu)
  OMEGA cible    : I=0.87 / E=0.32 → 2.72 (best-seller probable + qualité)

Seuil > 2.0 = bestseller potentiel
Seuil > 3.5 = bestseller de masse probable
```

### 6.3 IPC — Indice de Pression Culturelle

```
IPC(t) = 0.20·C + 0.15·P + 0.18·T + 0.17·S + 0.10·G + 0.08·CL + 0.07·M + 0.05·B

IPC 2024-2025 : 7.2-7.4 / 10 — pression haute stable
IPC 2026-2028 estimé : 7.4-7.8 / 10 — IA + Climat montants
```

### 6.4 Boost_prix dans P_sociale

```
Poids par prix (calibrés sur données Barabási + données françaises) :
```

## 8. TABLE DES PRIX LITTÉRAIRES — RÉSUMÉ EXÉCUTIF

### 8.1 Les 3 types de dissonance documentés

| Type | Description | Exemples |
|------|-------------|---------|
| **Type A** | Primé + peu vendu + peu aimé | Handke (Nobel), Jelinek (Nobel), Modiano (Nobel) |
| **Type B** | Peu primé + massivement vendu + adoré | Stephen King, Colleen Hoover, J.K. Rowling |
| **Type C (zone OMEGA)** | Primé + vendu + adoré | Hosseini, Doerr (Pulitzer), Handmaid's Tale, Stockett |

### 8.2 Loi de la dissonance

```
JURY cherche      : Innovation + Ambition + Style pur
                  → maximise Effort cognitif (E ↑)
                  → ne maximise pas I/E

LECTEUR cherche   : Identification + Arc satisfaisant + Transportation
                  → maximise Intensité / minimise Effort (I/E ↑)

ZONE OMEGA        : max(Prix × Ventes × Amour) simultanément
                  → I/E ≥ 1.8 ET style innovant ET thème résonant
                  → représente ~5-8% des bestsellers sur 35 ans
```

### 8.3 Score OMEGA complet avec prix

```
SCORE_OMEGA_COMPLET = 0.35·Q_prose + 0.30·R_commerciale + 0.15·P_prix + 0.20·V_viralité

Seuils :
  ≥ 88 : Chef d'œuvre + best-seller mondial (Zone C)
  75-87 : Best-seller national + reconnaissance critique possible
  60-74 : Best-seller régional + intérêt éditorial fort
  < 60  : Niche ou confidentiel

OMEGA cible : ≥ 88 (Handmaid's Tale level estimé à ~92)
```
