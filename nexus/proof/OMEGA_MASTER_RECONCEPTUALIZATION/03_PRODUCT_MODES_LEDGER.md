# 03_PRODUCT_MODES_LEDGER — les 6 usages produit, maturité RÉELLE
**Grille : but / entrée / sortie / modules existants / manquants / maturité / risques / preuves.**

## AUTONOMOUS_BOOK — maturité ★★★★☆ (PROUVÉ, non publiable sans V1 éditoriale)
**But** : un livre complet meilleur que la production moyenne, à partir d'instructions simples OU d'une Bible canonique remplie (lieux, personnages, monde). **Entrée** : BookIntent (aujourd'hui) ; IntentPack/Bible remplie (cible). **Sortie** : MANUSCRIT.md + 1 admission rejouable/chapitre + audits. **Existant** : TOUTE la chaîne C0→C9 + planner P1.B + extension 60k. **Manquant** : entrée Bible-remplie (UI/IntentPack), quotas de fonctions dramatiques au plan, cooldown tics branché, casting TOTAL obligatoire. **Risques** : tout ce qui n'est pas minté dérive (PROUVÉ) ; tics d'imaginaire. **Preuves** : runs/c8_book60k (50 chap, 87 987 mots, 349/350, V1 réparée).

## REWRITE_DOCTOR — maturité ★★★☆☆ (le plus PROCHE de l'assemblage)
**But** : l'utilisateur donne un roman ; OMEGA audite cohérence/qualité et réécrit le nécessaire SEULEMENT (conserver/corriger/fusionner/couper/réécrire/signaler). **Entrée** : manuscrit externe. **Sortie** : AUDIT 3 niveaux + ledger + REPAIR diff + V1. **Existant** : GO_B 2026-05-29 ; C9 (où réparer) ; V2.3 rewritePrompt+REWRITE_ORACLE (comment) ; N2 factuel ; doctrine prouvée (V1 Repair 88k : minimal-intervention, faux-UNPAID refusé). **Manquant** : pipeline d'IMPORT (split chapitres arbitraires, casting auto via scanner C2 sur texte importé), orchestrateur doctor, UI. **Risques** : trahir l'intention (BF-12) ; proxys trop bêtes pris pour vérité (leçon lettre/registre). **Preuves** : C9_EVIDENCE + C10_EVIDENCE.

## MYCELIUM_DNA — maturité ★★★☆☆ (mécanique scellée, contenu narratif à projeter)
**But** : carte ADN unique d'un roman, déterministe, reproductible (même roman ⇒ même Mycelium ⇒ même hash). **Entrée** : roman + config. **Sortie** : génome (émotionnel + narratif) + visualisation (phase 17). **Existant** : genome SEALED (SHA-256, Emotion14, 109t), mycelium FROZEN (gardien, 97t), dna.ts UI 128d ; ET les structures narratives 2026-06 (journal identité, Bible, admissions, seedLedger, fonctions de chapitres). **Manquant** : l'EXPORTEUR narratif → format génome (BF-13), unicité/reproductibilité testée sur le 88k. **Risques** : mélanger empreinte émotionnelle et narrative sans schéma versionné. **Preuves** : packages/genome tests ; VISION §5 (usages monétisables actés).

## STYLE_CONTINUATION — maturité ★★☆☆☆ (briques codées, flux absent)
**But** : copier un style, continuer une œuvre, écrire un tome ENTRE deux tomes sans erreur de canon. **Entrée** : œuvre(s) de référence + RIGHTS_MODE. **Sortie** : prose conforme style+canon. **Existant** : VoiceGenome+compiler (codés, calibrés), spec mode continuation (V_floor 85, fingerprint ±10%), Story-State figeable fin-de-tome, rights-gate GRAVÉE (VISION §8). **Manquant** : extracteur auto référence→VoiceGenome, SAGA_CONTRACT (promesses inter-tomes), enum RIGHTS_MODE machine-level, validation anti-anachronisme (canon-kernel le permet). **Risques** : juridique (bloqué par design) ; pastiche plat (mesurer V). **Preuves** : sovereign-engine/src/voice/*.

## COAUTHOR_GPS — maturité ★★☆☆☆ (vision+radar, trajectoires+UI à créer)
**But** : pendant que l'écrivain écrit, OMEGA montre position/trajectoire/chemins/dangers et suggère des dérivations (3-5 routes typées). **NE DÉCIDE JAMAIS.** **Entrée** : texte en cours de frappe + Bible. **Sortie** : alertes (radar) + trajectoires alternatives + relances. **Existant** : le RADAR complet (extracteur C4+diff, C9 phrase/chapitre/arc, continuity-oracle, recall scanner) fonctionne sur prose arbitraire ; organe NARRATIVE_FLOW acté ; potards de trajectoire actés. **Manquant** : trajectory-predictor (0 code), gps-narratif-core (0 code), UI WRITING STUDIO (phase 18), incrémental temps réel. **Risques** : latence ; sur-alerte (advisory fatigue). **Preuves** : VISION §6 ; DEC:48 ; ROADMAP ph.7.

## MIXER_CONTROL — maturité ★★☆☆☆ (science faite, engine à créer)
**But** : potards (tension/romance/mystère/violence/espoir, puis rythme/peur/suspense/dialogue/intériorité/sensoriel…) pilotant la TRAJECTOIRE. **Entrée** : positions de potards. **Sortie** : modifications mesurables de la sélection/du plan + rapport de traçabilité par potard (BF-10). **Existant** : science Rosetta (PILOTABLE/ILLUSION, L10, bridge V5 compliance 100%), 16 émotions M/λ/κ (la vraie table de mixage), leviers réels = pondération Best-of-N + cibles gates + profils/amorces + contrat plan. **Manquant** : potards-engine (mapping potard→leviers), C_MASTER runtime, UI COCKPIT. **Risques** : Goodhart (BF-15) ; potard-placebo si feature ILLUSION. **Preuves** : docs/irm/*, ADR-003.
