# 10_REPRISE_PROTOCOL — le rituel anti-oubli de CHAQUE session OMEGA
**Ce protocole est EXÉCUTOIRE : il est référencé en tête du CLAUDE.md du repo (auto-chargé à chaque session) et en tête de la mémoire Cowork. Une IA qui ne le suit pas produit des réponses INVALIDES.**

## LE RITUEL (6 étapes, ~5 minutes)
1. **LIRE** `00_READ_ME_FIRST.md` (ce dossier). Pas de raccourci, même si « on connaît ».
2. **RÉSOUDRE la demande en Concept-IDs** : chercher dans `02_CONCEPT_LEDGER.md` (penser SYNONYMES — chaque concept liste les siens : « potards » = mixer/curseurs/sliders/C_MASTER/pilotable…).
3. **CHARGER le contexte du mode** : si la demande touche un usage produit → `03_PRODUCT_MODES_LEDGER.md` (maturité réelle, manquants, risques).
4. **VÉRIFIER les modules** : `04_MODULE_DNA_LEDGER.md` + `07_RUNTIME_MAP.md` — ne JAMAIS affirmer « X n'existe pas » sans les avoir consultés ; les statuts se composent (FROZEN+ORPHAN+servi-via-ACL) ; une FONCTION peut vivre sous un autre nom (THE_SKEPTIC→C9).
5. **VÉRIFIER les décisions et lois** : `05_DECISION_LEDGER.md` + `06_CODEX_RULES_LEDGER.md` — une proposition qui contredit une décision scellée est morte-née ; une dérogation = STOP + demande Architecte.
6. **RÉPONDRE** en ouvrant par la déclaration : **FOUND_EXISTING** (Concept-ID + sources + ce qu'on adapte) ou **NEW_CONCEPT** (ID proposé + justification + liens). Sans cette déclaration = HORS PROTOCOLE.

## EN FIN DE SESSION (SESSION_SAVE_RITUAL — DEC-20260121-001:151, jamais optionnel)
- Toute décision Architecte → ligne dans `05_DECISION_LEDGER.md` (+ DEC-* si majeure).
- Tout concept nouveau/retrouvé → entrée/mise à jour dans `02_CONCEPT_LEDGER.md`.
- Tout changement de statut module (codé/branché/scellé) → `04` + `07`.
- Toute leçon durcie (morsure type localeCompare/\b-accents) → `06_CODEX_RULES_LEDGER.md` §prose/mesure.
- Mémoire Cowork : mettre à jour la carte maîtresse (pointeur, pas contenu).
**La mise à jour des ledgers fait partie du livrable — un travail non consigné ici est réputé PERDU.**

## RÈGLES DE CHARGE (pour les IA sans accès repo : ChatGPT/Gemini)
Le porteur du repo (Cowork/Claude Code) DOIT coller dans le prompt tribunal : 00_READ_ME_FIRST + les entrées 02/03 pertinentes du sujet. Un avis tribunal rendu sans ces extraits est réputé sous-informé (le signaler).
